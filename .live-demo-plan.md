# graphtask Live-Tracking Smoke Test

Theme: **Escape from Helgen** (Skyrim opener). Fictional plan, real graph operations.

## Goal of the test

Demonstrate the graphtask skill end-to-end against a live graph the user is watching, exercising:

- Initial bulk-graph materialization (13 nodes, 17 edges)
- Branching + converging DAG (parallel work + join nodes)
- Mixed edge types (`dependency` and `related`)
- Full status lifecycle on every task: `todo → in_progress → review → done`
- Self-review override: when forward progress is blocked only by my own `review` tasks, I review them myself and mark `done` (skill normally forbids this — user has explicitly authorized for the smoke test)
- Edge mutation mid-run: one edge type swap (`dependency` ↔ `related`) and one edge repoint (change source or target)
- Blocker query: at least one attempted-start that surfaces blockers via `GET /tasks/:id/blockers`

## Pacing strategy (target: ≤ 2 minutes wall-clock)

The big cost is LLM reasoning between bash calls, not the API. So:

- **One bash call per phase** with a loop and short `sleep` between transitions, so the canvas updates are visually paced (~0.4s) without me re-entering the LLM 50 times.
- **Terse bodies** (≤120 chars) — bodies are demo placeholders, not real work artifacts.
- **5 total bash calls** end-to-end: setup + 4 phases. ≤30s of actual API/sleep time + 5 short narration turns.

## Setup (Bash call #1)

Create a fresh dedicated graph. Do NOT touch `.graphtask/graph-id`. Persist the smoke graph id to `/tmp/smoke-gid` and task ids to `/tmp/smoke-tasks.env` so subsequent phases can source them.

```bash
GT_BASE="${GRAPHTASK_BASE_URL:-http://127.0.0.1:3000}"
SMOKE_GID=$(curl -sS -X POST "$GT_BASE/api/graphs" \
  -H 'Content-Type: application/json' \
  -d '{"name":"Smoke test: Escape from Helgen","description":"Live-tracking smoke test."}' \
  | jq -r .id)
echo "$SMOKE_GID" > /tmp/smoke-gid
echo "Graph: $GT_BASE/g/$SMOKE_GID"

mk() {
  local title="$1" body="$2"
  curl -sS -X POST "$GT_BASE/api/graphs/$SMOKE_GID/tasks" \
    -H 'Content-Type: application/json' \
    -d "$(jq -n --arg c "---
title: $title
status: todo
---
$body
" '{content:$c}')" | jq -r .id
}

T1=$(mk  "Wake up in the cart"                    "Open eyes; learn we're prisoners.")
T2=$(mk  "Survive dragon attack on Helgen"        "Dragon arrives. Find cover.")
T3=$(mk  "Pick escape companion (Hadvar)"         "Choose the Imperial side.")
T4=$(mk  "Reach the keep entrance"                "Cross the burning village.")
T5a=$(mk "Find armor inside the keep"             "Loot light armor from chest.")
T5b=$(mk "Find weapons inside the keep"           "Grab a sword and bow.")
T6=$(mk  "Equip gear and breach the barracks"     "JOIN: needs T5a + T5b.")
T7=$(mk  "Escape through the torture chamber"     "Fight Stormcloaks; free mage.")
T8a=$(mk "Sneak past the frostbite spider"        "Stealth.")
T8b=$(mk "Sneak past the sleeping bear"           "Stealth-archery.")
T9=$(mk  "Exit the cave into Skyrim"              "JOIN: needs T8a + T8b.")
T10=$(mk "Travel to Riverwood"                    "Meet Alvor at the forge.")
T11=$(mk "Talk to Alvor for a recommendation"     "Optional: Alvor writes a note.")
T12=$(mk "Travel to Whiterun"                     "Walk the road north.")
T13=$(mk "Report to Jarl Balgruuf"                "Deliver news of the dragon.")

cat > /tmp/smoke-tasks.env <<EOF
SMOKE_GID=$SMOKE_GID

T3=$T3
T4=$T4
T5a=$T5a

T8b=$T8b

curl -sS -X POST "$GT_BASE/api/graphs/$SMOKE_GID/edges/bulk" \
  -H 'Content-Type: application/json' \
  -d "$(jq -n \
    --argjson t1 $T1 --argjson t2 $T2 --argjson t3 $T3 --argjson t4 $T4 \
    --argjson t5a $T5a --argjson t5b $T5b --argjson t6 $T6 --argjson t7 $T7 \
    --argjson t8a $T8a --argjson t8b $T8b --argjson t9 $T9 --argjson t10 $T10 \
    --argjson t11 $T11 --argjson t12 $T12 --argjson t13 $T13 \
    '{edges:[
      {source_id:$t1,target_id:$t2,type:"dependency"},
      {source_id:$t2,target_id:$t3,type:"dependency"},
      {source_id:$t3,target_id:$t4,type:"dependency"},
      {source_id:$t4,target_id:$t5a,type:"dependency"},
      {source_id:$t4,target_id:$t5b,type:"dependency"},
      {source_id:$t5a,target_id:$t6,type:"dependency"},
      {source_id:$t5b,target_id:$t6,type:"dependency"},
      {source_id:$t6,target_id:$t7,type:"dependency"},
      {source_id:$t7,target_id:$t8a,type:"dependency"},
      {source_id:$t7,target_id:$t8b,type:"dependency"},
      {source_id:$t8a,target_id:$t9,type:"dependency"},
```

## Helper (defined at the top of every phase script)

```bash
source /tmp/smoke-tasks.env
GT_BASE="${GRAPHTASK_BASE_URL:-http://127.0.0.1:3000}"
PAUSE=0.4

# bump <task_id> <new_status> <title> <body>
bump() {
  local id="$1" status="$2" title="$3" body="$4"
  curl -sS -X PATCH "$GT_BASE/api/graphs/$SMOKE_GID/tasks/$id" \
    -H 'Content-Type: application/json' \
    -d "$(jq -n --arg c "---
title: $title
status: $status
---
$body
" '{content:$c}')" >/dev/null
  sleep "$PAUSE"
}

# cycle <task_id> <title> — runs todo→in_progress→review→done with terse bodies
cycle() {
  local id="$1" title="$2"
  bump "$id" in_progress "$title" "Working..."
  bump "$id" review      "$title" "Done. Self-review: looks good."
  bump "$id" done        "$title" "Approved."
}
```

## Phase 1 — linear warm-up + blocker demo + edge swap (Bash call #2)

T1 → T4. Demonstrate blocker query and edge type swap.

```bash
# T1: full lifecycle but pause at review to demo blocker query
bump "$T1" in_progress "Wake up in the cart" "Opening eyes..."
bump "$T1" review      "Wake up in the cart" "Awake. Awaiting cart-arrival."

# Try to start T2 while T1 is review — show blockers
echo "--- blockers for T2 (T1 should appear) ---"
curl -sS "$GT_BASE/api/graphs/$SMOKE_GID/tasks/$T2/blockers" | jq '.[] | {id, status: .meta.status, title: (.content | capture("title: (?<t>[^\n]+)") | .t)}'

# Self-review T1 → done
bump "$T1" done "Wake up in the cart" "Approved."

# T2 full cycle
cycle "$T2" "Survive dragon attack on Helgen"

# T3 full cycle
cycle "$T3" "Pick escape companion (Hadvar)"

# Edge type swap demo: flip T2→T3 to related, then back to dependency
EID_T2_T3=$(curl -sS "$GT_BASE/api/graphs/$SMOKE_GID/edges" \
  | jq ".[] | select(.source_id==$T2 and .target_id==$T3) | .id")
echo "--- swapping edge T2→T3 to related ---"
curl -sS -X PATCH "$GT_BASE/api/graphs/$SMOKE_GID/edges/$EID_T2_T3" \
  -H 'Content-Type: application/json' -d '{"type":"related"}' >/dev/null
sleep 0.8
echo "--- swapping back to dependency ---"
curl -sS -X PATCH "$GT_BASE/api/graphs/$SMOKE_GID/edges/$EID_T2_T3" \
  -H 'Content-Type: application/json' -d '{"type":"dependency"}' >/dev/null
sleep 0.4

# T4 full cycle
cycle "$T4" "Reach the keep entrance"

echo "--- ready tasks after Phase 1 ---"
curl -sS "$GT_BASE/api/graphs/$SMOKE_GID/tasks/ready" | jq 'length'
```

## Phase 2 — first parallel branch + join (Bash call #3)

T5a + T5b parallel → T6 join.

```bash
# Show ready set: should contain both T5a and T5b
curl -sS "$GT_BASE/api/graphs/$SMOKE_GID/tasks/ready" \
  | jq '[.[] | (.content | capture("title: (?<t>[^\n]+)") | .t)]'

# Move both to in_progress (interleaved)
bump "$T5a" in_progress "Find armor inside the keep"   "Searching chests..."
bump "$T5b" in_progress "Find weapons inside the keep" "Checking the rack..."

# Both to review
bump "$T5a" review "Find armor inside the keep"   "Got the armor."
bump "$T5b" review "Find weapons inside the keep" "Got sword + bow."

# Self-review both → done
bump "$T5a" done "Find armor inside the keep"   "Approved."
bump "$T5b" done "Find weapons inside the keep" "Approved."

# T6 join
cycle "$T6" "Equip gear and breach the barracks"
```

## Phase 3 — edge repoint demo + second parallel branch + join (Bash call #4)

T7 → T8a/T8b parallel → T9. Repoint the related T11→T13 edge to T11→T12 mid-phase, then back.

```bash
# T7
cycle "$T7" "Escape through the torture chamber"

# Edge repoint demo on the related edge T11→T13
EID_T11_T13=$(curl -sS "$GT_BASE/api/graphs/$SMOKE_GID/edges" \
  | jq ".[] | select(.source_id==$T11 and .target_id==$T13) | .id")
echo "--- repointing related edge T11→T13 to T11→T12 ---"
curl -sS -X PATCH "$GT_BASE/api/graphs/$SMOKE_GID/edges/$EID_T11_T13" \
  -H 'Content-Type: application/json' -d "{\"target_id\":$T12}" >/dev/null
sleep 0.8
echo "--- repointing back to T11→T13 ---"
curl -sS -X PATCH "$GT_BASE/api/graphs/$SMOKE_GID/edges/$EID_T11_T13" \
  -H 'Content-Type: application/json' -d "{\"target_id\":$T13}" >/dev/null
sleep 0.4

# T8a + T8b parallel
bump "$T8a" in_progress "Sneak past the frostbite spider" "Stealthing..."
bump "$T8b" in_progress "Sneak past the sleeping bear"    "Stealthing..."
bump "$T8a" review "Sneak past the frostbite spider" "Past the spider."
bump "$T8b" review "Sneak past the sleeping bear"    "Past the bear."
bump "$T8a" done   "Sneak past the frostbite spider" "Approved."
bump "$T8b" done   "Sneak past the sleeping bear"    "Approved."

# T9 join
cycle "$T9" "Exit the cave into Skyrim"
```

T10 → T11/T12 parallel → T13.
